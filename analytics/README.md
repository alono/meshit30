# נתוני שימוש

שתי מערכות, כל אחת עונה על מה שהשנייה לא יכולה:

| | Cloudflare Web Analytics | הטבלה שלנו ב-D1 |
|---|---|---|
| מה מקבלים | תנועה, מדינה, סוג מכשיר, דפדפן, מקור הגעה, מהירות טעינה | כמה מכשירים שונים, כמה מהם חוזרים, אילו מסכים נפתחו |
| איפה קוראים | Workers & Pages ← meshit30 ← Metrics | D1 ← meshit30-usage ← Console, עם `queries.sql` |
| מה עולה | חינם, בלי תחזוקה | חינם עד 100,000 כתיבות ליום; אנחנו בערך ב-800 |
| קוד במאגר | אין — הסקריפט מוזרק בקצה | `functions/api/v.js` + `analytics/` |

## הקמה — שלושה שלבים חד-פעמיים בממשק

1. **הפעלת Web Analytics:** Workers & Pages ← meshit30 ← **Metrics** ← **Enable**
   תחת Web Analytics. הסקריפט נוסף אוטומטית לאתר בפריסה הבאה.
2. **יצירת מסד הנתונים:** Storage & Databases ← **D1** ← **Create database** בשם
   `meshit30-usage`. לפתוח **Console** ולהדביק את `analytics/schema.sql`.
3. **חיבור המסד לאתר:** Workers & Pages ← meshit30 ← **Settings** ← **Bindings** ←
   **Add** ← **D1 database**. שם המשתנה חייב להיות `DB` (כך `functions/api/v.js` מחפש
   אותו), ולבחור את `meshit30-usage`. לאחר מכן לפרוס מחדש.

עד שהשלב השלישי מתבצע, הנקודה `/api/v` פשוט לא כותבת דבר ומחזירה 204 — אפשר לפרוס את
הקוד לפני ההקמה בלי לשבור כלום.

## מה נאסף

שורה אחת לכל (תאריך, מכשיר, מסך, נושא), עם מונה. זה הכול. אין שעה, אין כתובת IP, אין
תשובות, אין ציונים, ואין שום דבר על איך מישהו הסתדר במבחן. ההתקדמות עצמה נשמרת במכשיר
בלבד ולא נשלחת לשום מקום.

מזהה המכשיר הוא מספר אקראי שנוצר בדפדפן ונשמר תחת `meshit30:aid:v1`. הוא נשמר **מחוץ**
לקידומת שהייצוא והייבוא עוברים עליה, כדי ששחזור גיבוי במכשיר שני לא ישכפל את המזהה. אפשר
לכבות את האיסוף לגמרי במסך הבית, תחת "נתוני שימוש".

## הכתובות

הספירה לפי מסכים עובדת כי לכל מסך יש כתובת אמיתית (`src/lib/route.js`):

```
/                            מסך הבית
/signals                     אורות וסימנים
/s/<slug>                    תפריט הנושא
/s/<slug>/learn              שינון
/s/<slug>/practice           תרגול
/s/<slug>/exam               סימולציה
/s/<slug>/exam/results       תוצאות
/s/<slug>/study              חומר עזר
/s/<slug>/progress           התקדמות
```

## מגבלות שכדאי לזכור לפני שקוראים את המספרים

* **שימוש לא מקוון אינו נספר.** האפליקציה עובדת אופליין, ומי שלומד בלי רשת לא מגיע לאף
  אחת משתי המערכות. שתיהן מספרות פחות מהאמת.
* "Visits" של Cloudflare הוא הגעה מאתר אחר, לא אדם. "Devices" שלנו קרוב יותר, אבל מכשיר
  אינו אדם.
* Cloudflare שומר נתונים מלאים שבעה ימים ובלוח המחוונים חצי שנה. הטבלה שלנו שומרת הכול עד
  שמריצים את שאילתת הניקוי (שאילתה 6).
